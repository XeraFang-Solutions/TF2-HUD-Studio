# Shortcuts

On macOS, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>.

## Everywhere
| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save all changed files |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Go to a file or element |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Search the whole HUD |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Open the current file in your text editor |

## Designer
| Keys / mouse | Action |
| --- | --- |
| Click, or <kbd>Shift</kbd>/<kbd>Ctrl</kbd>+click | Select, or add to the selection |
| Drag on an empty area | Select with a box |
| Arrow keys / <kbd>Shift</kbd>+arrows | Nudge 1 / 10 units |
| <kbd>Alt</kbd>+drag | Move without snapping |
| <kbd>Shift</kbd>+drag a handle | Resize, keeping the aspect ratio |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Zoom to fit |
| <kbd>Esc</kbd> | Clear the selection |

## Fields and dropdowns
| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Apply a value |
| <kbd>Esc</kbd> | Cancel the edit, or close a dropdown |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through suggestions or dropdown items |
| Typing a letter | Jump to a matching dropdown item |

## Tabs and lists
| Mouse | Action |
| --- | --- |
| Middle-click a tab | Close it |
| Right-click a file or tab | Open in your text or image editor, or show it in its folder |
| Right-click a problem | Open in your text editor at that line |
